## 📌 What Is shadcn/ui?

shadcn/ui is **not a traditional component library**. It is a collection of beautifully designed, accessible React components that are **copied directly into your project** — you own every line of code. There is no npm package to import; there is no version lock-in.

Key facts:
- Built on **Radix UI** primitives (headless, accessible)
- Styled with **Tailwind CSS** (utility-first)
- Works with **Next.js, Vite, Astro, React Router, TanStack Start**
- Fully compatible with **TypeScript**
- Trusted by OpenAI, Adobe, Sonos, and more

## ⚙️ Setup — Do This First in Every New Project

### Step 1 — Create the Next.js project (if not already done)
```bash
npx create-next-app@latest my-app --typescript --tailwind --app --src-dir
cd my-app
```

### Step 2 — Initialize shadcn/ui
```bash
npx shadcn@latest init
```

During init, choose:
- **Style**: `new-york` ← (more refined, preferred)
- **Base color**: match the project's brand (Neutral is a safe default)
- **CSS variables**: `yes`

This creates `components.json` at the project root. Do **not** delete it.

### Step 3 — Add components as needed
```bash
npx shadcn@latest add button card dialog form input table tabs
```

To add ALL components at once (for full projects):
```bash
npx shadcn@latest add accordion alert alert-dialog avatar badge breadcrumb button calendar card carousel chart checkbox collapsible command context-menu dialog drawer dropdown-menu form hover-card input input-otp label menubar navigation-menu pagination popover progress radio-group resizable scroll-area select separator sheet sidebar skeleton slider sonner switch table tabs textarea toggle toggle-group tooltip
```

Components are placed in `src/components/ui/` — you can edit them freely.

## 🎨 Theming & Brand Colors

shadcn/ui uses **CSS variables** for all colors. After init, open `src/app/globals.css` and customize:

```css
@layer base {
  :root {
    --background: 0 0% 100%;
    --foreground: 222.2 84% 4.9%;
    --primary: 221.2 83.2% 53.3%;       /* ← Change to brand color */
    --primary-foreground: 210 40% 98%;
    --secondary: 210 40% 96.1%;
    --accent: 210 40% 96.1%;
    --destructive: 0 84.2% 60.2%;
    --radius: 0.5rem;                    /* ← Controls border radius globally */
  }

  .dark {
    --background: 222.2 84% 4.9%;
    --foreground: 210 40% 98%;
    /* ... dark mode overrides */
  }
}
```

> ⚠️ Colors use HSL format WITHOUT the `hsl()` wrapper. Example: `#2E7D32` green → `123 45% 34%`

### Converting HEX to shadcn HSL format:
1. Convert HEX → HSL (use any online tool)
2. Write only the three values: `H S% L%`
3. Paste into the CSS variable

## 🧩 The `cn()` Utility — Always Use It

The `cn()` function merges Tailwind classes cleanly. Always use it for conditional styling:

```tsx
import { cn } from "@/lib/utils"

// Instead of template literals:
<div className={cn(
  "base-class px-4 py-2",
  isActive && "bg-primary text-primary-foreground",
  isDisabled && "opacity-50 cursor-not-allowed"
)} />
```

## 🧑‍💻 How to Use Components — Code Patterns

### Basic Button
```tsx
import { Button } from "@/components/ui/button"

<Button variant="default">Submit</Button>
<Button variant="outline">Cancel</Button>
<Button variant="destructive">Delete</Button>
<Button variant="ghost">Ghost</Button>
<Button size="sm">Small</Button>
<Button size="lg">Large</Button>
```

### Card
```tsx
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from "@/components/ui/card"

<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
    <CardDescription>Subtitle or description</CardDescription>
  </CardHeader>
  <CardContent>
    Main content goes here
  </CardContent>
</Card>
```

### Dialog (Modal)
```tsx
import { Dialog, DialogContent, DialogHeader, DialogTitle, DialogTrigger } from "@/components/ui/dialog"

<Dialog>
  <DialogTrigger asChild>
    <Button>Open</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Modal Title</DialogTitle>
    </DialogHeader>
    {/* content */}
  </DialogContent>
</Dialog>
```

### Form with Validation (React Hook Form + Zod)
```tsx
import { useForm } from "react-hook-form"
import { zodResolver } from "@hookform/resolvers/zod"
import * as z from "zod"
import { Form, FormControl, FormField, FormItem, FormLabel, FormMessage } from "@/components/ui/form"
import { Input } from "@/components/ui/input"
import { Button } from "@/components/ui/button"

const schema = z.object({ email: z.string().email() })

export function MyForm() {
  const form = useForm({ resolver: zodResolver(schema) })
  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit((data) => console.log(data))}>
        <FormField control={form.control} name="email" render={({ field }) => (
          <FormItem>
            <FormLabel>Email</FormLabel>
            <FormControl><Input {...field} /></FormControl>
            <FormMessage />
          </FormItem>
        )} />
        <Button type="submit">Submit</Button>
      </form>
    </Form>
  )
}
```

> Install deps: `npm install react-hook-form @hookform/resolvers zod`

### Toast Notifications (Sonner)
```tsx
// In layout.tsx
import { Toaster } from "@/components/ui/sonner"
<Toaster />

// Anywhere in app
import { toast } from "sonner"
toast.success("Saved successfully!")
toast.error("Something went wrong")
```

### Data Table
```tsx
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table"

<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Name</TableHead>
      <TableHead>Status</TableHead>
    </TableRow>
  </TableHeader>

      <TableRow key={row.id}>
        <TableCell>{row.name}</TableCell>
        <TableCell><Badge>{row.status}</Badge></TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>
```

## 🌙 Dark Mode Setup

Install the theme provider:
```bash
npm install next-themes
```

Wrap your app in `src/app/layout.tsx`:
```tsx
import { ThemeProvider } from "next-themes"

export default function RootLayout({ children }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  )
}
```

Toggle button:
```tsx
import { useTheme } from "next-themes"
import { Button } from "@/components/ui/button"
import { Moon, Sun } from "lucide-react"

export function ThemeToggle() {
  const { theme, setTheme } = useTheme()
  return (
    <Button variant="ghost" size="icon" onClick={() => setTheme(theme === "dark" ? "light" : "dark")}>
      <Sun className="h-4 w-4 rotate-0 scale-100 dark:-rotate-90 dark:scale-0" />
      <Moon className="absolute h-4 w-4 rotate-90 scale-0 dark:rotate-0 dark:scale-100" />
    </Button>
  )
}
```

## 📐 Layout & Responsive Design Rules

Always design **mobile-first**. Use Tailwind breakpoints:

| Breakpoint | Prefix | Width |
|---|---|---|
| Mobile (default) | _(none)_ | < 640px |
| Small | `sm:` | ≥ 640px |
| Medium | `md:` | ≥ 768px |
| Large | `lg:` | ≥ 1024px |
| XL | `xl:` | ≥ 1280px |

### Common Layout Patterns

**Centered container:**
```tsx
<main className="container mx-auto px-4 py-8 max-w-7xl">
```

**Responsive grid:**
```tsx
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
```

**Flex row → column on mobile:**
```tsx
<div className="flex flex-col md:flex-row gap-4">
```

## ✅ UI Quality Checklist

Before considering any UI done, verify:

- [ ] All interactive elements have **hover & focus states**
- [ ] Keyboard navigation works (Tab, Enter, Escape)
- [ ] Mobile layout tested at 375px, 768px, 1280px
- [ ] Dark mode matches light mode quality
- [ ] Loading states exist for all async actions (use `Skeleton`)
- [ ] Error states exist for all forms (use `FormMessage`)
- [ ] Toast notifications confirm destructive / important actions
- [ ] Typography scale is consistent (`text-sm`, `text-base`, `text-lg`, `text-xl`, `text-2xl`, `text-4xl`)
- [ ] Spacing is consistent (use multiples of 4: `p-4`, `gap-8`, `mt-12`)
- [ ] `aria-label` on icon-only buttons

## 🚫 Anti-Patterns — Never Do These

```tsx
// ❌ Don't use inline styles when Tailwind classes exist
<div style={{ marginTop: "16px" }}>

// ✅ Do this
<div className="mt-4">
```

```tsx
// ❌ Don't hardcode colors
<div className="bg-[#2E7D32]">

// ✅ Use CSS variables via Tailwind
<div className="bg-primary">
```

```tsx
// ❌ Don't skip the cn() utility for conditional classes
<div className={`btn ${isActive ? "active" : ""}`}>

// ✅ Use cn()
<div className={cn("btn", isActive && "active")}>
```

```tsx
// ❌ Don't import from wrong path
import { Button } from "shadcn/ui"

// ✅ Always import from local components
import { Button } from "@/components/ui/button"
```

## 💡 Instructions for Claude Code (AI Assistant)

When starting a project using this guide:

1. **Read this file first** before writing any component code
2. **Use shadcn/ui components** from `@/components/ui/` — do not invent custom UI from scratch when a shadcn component covers the need
3. **Run `npx shadcn@latest add [component]`** for each component before importing it
4. **Follow the folder structure** defined above
5. **Apply the brand colors** provided by the user into `globals.css` CSS variables
6. **Always implement dark mode** unless explicitly told not to
7. **Mobile-first**: every layout must work at 375px width
8. **Never skip the UI Quality Checklist** before declaring a page done
9. When in doubt about a component's API, check `src/components/ui/[component].tsx` — the source is right there
